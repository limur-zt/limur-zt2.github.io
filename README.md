# Первые 15 минут

Интерактивный тренажёр цифровой безопасности для студентов 1–2 курсов по информационной безопасности.

## Запуск
1. Откройте `index.html` в браузере.
2. Никакой установки, сервера или базы данных не требуется.
3. Для публикации загрузите `index.html` на любой статический хостинг.

## Состав MVP
- 4 интерактивных сценария;
- выбор вариантов действий;
- мгновенный разбор решения;
- итоговый результат 0–4;
- таймер на 15 минут;
- финальный чек-лист;
- адаптивная мобильная верстка.

Все персонажи, сообщения и домены в сценариях вымышлены.
